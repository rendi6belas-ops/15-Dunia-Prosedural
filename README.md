# 15 Dunia Prosedural (Procedural Worlds)

Koleksi 15 dunia prosedural 3D interaktif yang dibangun menggunakan **WebGL2** dan teknik *raymarching* Signed Distance Functions (SDF). Setiap file HTML berdiri sendiri (*standalone*), tanpa memerlukan dependensi atau pustaka eksternal.

## 🌌 Daftar Dunia
1. **Europa** (Bulan es · Jupiter)
2. **Mars** (Gurun · Planet merah)
3. **Di Dalam Raksasa Gas** (Atmosfer · Raksasa gas)
4. **Orbit** (Orbit · Cincin es)
5. **Kanopi** (Hutan hujan · Subuh)
6. **Mirage** (Gurun · Oasis)
7. **Lembah Glasial** (Pegunungan · Salju)
8. **Gua Kristal** (Gua · Kristal)
9. **Bara** (Vulkanik · Lava)
10. **Terumbu** (Laut dangkal · Terumbu)
11. **Di Bawah Lapisan Es** (Bawah es · Kutub)
12. **Kota Tenggelam** (Reruntuhan · Kota tenggelam)
13. **Nave** (Arsitektur · Katedral)
14. **Gang Neon** (Kota · Hujan malam)
15. **Setetes Air** (Mikroskopis · Setetes air)

## 🎮 Kontrol Navigasi
Setiap dunia mendukung kontrol interaktif berikut langsung di peramban (browser):
* **Drag (Klik & Seret):** Melihat sekeliling / rotasi kamera.
* **W A S D / Tombol Panah:** Bergerak maju, mundur, ke kiri, dan ke kanan.
* **Shift:** Bergerak lebih cepat (*sprint*).
* **H:** Menyembunyikan atau menampilkan antarmuka HUD.

## 🚀 Cara Menjalankan
1. Clone atau download repository ini.
2. Buka file `index.html` langsung di browser modern (Chrome, Edge, atau Firefox) yang mendukung WebGL2.
3. (Opsional) Jika menggunakan VS Code, Anda bisa menjalankannya menggunakan ekstensi **Live Server**.

## 🛠️ Teknologi
* **WebGL2**
* **GLSL Raymarching Shaders**
* **Pure HTML5 / CSS3 / Vanilla JavaScript** (Tanpa framework tambahan)
